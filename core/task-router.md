# Task Router

这是可选进阶模式的轻量决策入口。日常只复制通用提示词即可，不要求读取本文件、填写计划或启用全部 Skills。先读当前项目实际规范，按复杂度选择 T0–T2；高影响风险优先提升到 T3，任务中出现新风险随时重判。

| 模式 | 判断信号 | 最少动作与加载 |
| --- | --- | --- |
| T0 直接执行 | 单一明确产物、低风险、局部且易撤销 | Core + 本路由；直接做并核对结果，不写长计划 |
| T1 轻量规划 | 多步但依赖简单，范围和方法基本已知 | 简短验收条件与步骤；需要领域方法时读对应 Skill；做产物检查 |
| T2 完整编排 | 跨模块/多产物/依赖复杂，或关键假设尚未验证 | 读取 task-orchestrator；按阶段选择领域 Skill 和对应 reference；记录依赖、验证与关键审查 |
| T3 风险加强 | 可能造成重大损失、敏感数据泄露，或重要外部发布、删除、资金、生产变更、高后果专业结论 | T2 + 风险/授权核对、回退与独立审查；缺失授权时停在高影响操作之前 |

T3 的正式独立审查由另一位获授权的人员/审查者承担；工具或任务授权不支持时，做有明确标记的自审，披露缺口。要求独立审查的闸门仍为阻塞，不能把角色切换说成独立审查。T3 不代表所有步骤都要反复请求确认。

## 领域路由

| 信号 | 读取 | 升级/组合条件 |
| --- | --- | --- |
| 投标、询价、报价响应、成套打印或邮寄 | [文档交付偏好](../docs/document-delivery-preferences.md) | 按本次指定格式及分封要求交付；多附件或多版本时加编排 |
| 跨阶段协调、复杂交付或 T2/T3 | [task-orchestrator](../skills/task-orchestrator/SKILL.md) | 只加载当前阶段需要的 reference |
| 封面、海报、UI、信息图、品牌视觉 | [visual-design](../skills/visual-design/SKILL.md) | 多规格或多素材依赖时加编排 |
| 脚本、分镜、剪辑、声音、字幕、导出 | [video-production](../skills/video-production/SKILL.md) | 视觉阶段再读 visual-design，勿启动即读全部 |
| 功能、修复、架构、测试与发布 | [software-engineering](../skills/software-engineering/SKILL.md) | 先用项目原有工具链，生产变更升 T3 |
| 调研、比较、证据整合、争议结论 | [deep-research](../skills/deep-research/SKILL.md) | 医疗/法律/财务等高后果结论升 T3，基础研究 Skill 不代替专业资质 |

## 加载协议

1. 启动：明确启用进阶模式时读取 Core、本路由与当前范围内项目规范。原生 Skill 目录可用时只发现名称和描述。
2. 选择：只读取当前相关 `SKILL.md`。没有自动发现能力时按上表人工路由，由 Agent 实际打开文件。
3. 深入：到拆解、审查、验收阶段再读取该 Skill 点名的 reference；模板只在需要记录时打开。Markdown 链接不是自动导入。
4. 路径：仓库链接以文件所在目录解析；安装入口中的 `.agent-os/` 以宿主项目根目录解析。共享安装须改为实际绝对路径。
5. 续作：保存产物位置、已读文件版本、已验证证据和待办；恢复时先读摘要与变化部分，不重复注入整个知识库。
6. 退出：交付时给出产物、验证、缺陷与限制。路由是选择框架，不会自动创建 Agent、调用工具或授予权限。

例：改一句标题 → T0；单封面 → T1 + visual-design；含配音字幕的成片 → T2 + 编排 + 视频；删除生产数据 → T3，先准备可审查方案与恢复证据，再核对授权。
