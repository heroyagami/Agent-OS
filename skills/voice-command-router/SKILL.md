# Voice Command Router

## 使命

把语音转写变成准确、可确认、可追踪的任务入口。负责识别意图和目标、发现歧义、分级风险并触发确认；不负责采集音频、声纹认证或绕过原有授权。

## 触发条件

- 用户通过语音或语音转写下达任务。
- 需要从口述内容识别目标文件、案件、人员、金额、日期或动作。
- 语音任务涉及发布、删除、对外发送、资金或生产变更。

纯文本且目标清晰时直接走 Task Router，不强制经过语音流程。

## 处理步骤

1. **接收转写**：只接收宿主提供的转写文本或私有引用。不要声称本 Skill 能打开麦克风或运行 STT。
2. **识别意图**：判断是创建任务、查询状态、取消任务、请求审查、请求发布、修改资源还是未知意图；无法确定时先询问。
3. **解析实体**：识别人名、案件、文件、金额、日期、对象和动作；重要实体保存私有引用与置信度，不把敏感值写入公开记录。
4. **消歧确认**：同名人员、多份文件、相似案件、金额/日期不清、否定词不确定或低置信度时，先回显理解并澄清。不得自行猜测对象。
5. **风险分级**：按 T0–T3 判断；高影响动作必须明确回显动作和目标，取得会话内明确确认，并走既有审批。
6. **认证与权限**：以已认证账户会话和工具权限为准。声音相似度、声纹或“听起来像本人”不能代替账户认证或审批。
7. **生成命令契约**：按 [Voice Command Schema](../../registry/schema/voice-command.schema.json) 记录脱敏元数据、私有引用、置信度、风险、确认和权限检查。
8. **路由派单**：创建任务时交给 [agent-dispatcher](../agent-dispatcher/SKILL.md)；查询/取消也须核对目标任务和权限。
9. **反馈结果**：回显已理解的目标、待确认项、执行状态和结果引用。没有宿主队列或语音工具时，说明只能生成命令/派单提案。
10. **保护隐私**：原始音频和完整转写留在受控私有系统；公开仓库只保存协议、Schema 和脱敏测试。

## 强制确认条件

- 目标对象不唯一、关键实体低置信度或语音转写存在歧义。
- T3 风险、发布、删除、外部发送、付款、生产变更或客户数据外发。
- 操作权限、审批人、任务范围或恢复方式不明确。

确认必须具体到动作和对象，例如“确认将某文件发布到某网站”，不能用泛泛的“好的”替代具体确认。用户明确拒绝时停止该动作。

## 交付验收

命令有可追踪 ID；意图与实体有置信度/消歧结果；风险、权限和认证状态清楚；高影响动作有明确确认和审批证据；敏感内容未进入公开记录；实际执行与仅生成提案严格区分。
