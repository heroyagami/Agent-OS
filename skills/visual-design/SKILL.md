# Visual Design

## 输入与方向

1. 读取原始文案、已有品牌/设计稿、素材授权与目标平台规格；确认受众、传播目的、主要信息、尺寸、裁切区、交付格式和可编辑源文件要求。
2. 从“观众先看见什么、读懂什么、采取什么动作”推导信息层级。未知规格先核实；低风险偏好可声明假设并推进。
3. 确定一个主方向和必要的备选理由，先用线框或低成本样稿验证布局与标题。关键假设可能是中文字体、缩略图可读性或素材可用性，先做小样。

## 分层制作

| 层 | 决策与检查 |
| --- | --- |
| 信息与构图 | 主信息、视觉重心、动线、留白、比例与安全区；先定层级再装饰 |
| 背景 | 场景/材质/明暗/景深是否服务于主体，避免噪声抢夺注意 |
| 主体 | 轮廓、比例、透视、光源、边缘和与背景的融合 |
| 字体 | 准确文案、字形、字号、字重、行距、对齐、对比和字体授权 |
| 色彩与细节 | 主色/辅助色/强调色、光影和纹理一致，装饰有明确功能 |
| 整合与适配 | 多规格裁切、实际展示尺寸、品牌一致性、UI 状态与交互（如适用） |

逐层制作但整体判断。已有设计稿要读取真实参数与资源；无法取得时说明依据，不伪称像素级还原。图像工具无法稳定生成准确文字时，分离图像与排字再合成。

## 审查与验收

- 以反对者视角看：最干扰信息的元素是什么，哪处层级不清、风格不一致或产生误读？缺陷必须对应实际画面。
- 打开真实导出图；核对目标尺寸、文案、无缺字、无遮挡、缩略图/裁切后的可读性。UI 还需查看真实布局与关键交互；无界面环境时标未验证。
- 修改真实 P0/P1/P2 缺陷；纯偏好更换须说明收益，不能无限重新生成。格式、尺寸和可编辑性属于硬约束。
- 交付最终图/预览、约定的源文件、素材与字体来源、已验证项目和限制。没有生成工具时可交付明确标记的设计方案，不能称已生成成品。

## 示例

16:9 课程封面：先确认标题与裁切规格 → 用灰阶布局检查主次 → 验证中文字体 → 完成背景、人物和标题 → 检查真实尺寸与缩略图 → 导出并回看。多张系列封面另需建立统一字体、色彩、主体比例与命名契约。
