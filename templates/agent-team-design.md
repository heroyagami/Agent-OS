## 组件选择：先判断该新增什么

| 需求 | 优先选择 | 新增 Agent 的必要理由 |
| --- | --- | --- |
| 可复用的固定方法 | Skill | 通常不需要 |
| 顺序明确、状态可预测的步骤 | Workflow | 仅当某环节需独立判断/权限时 |
| 搜索、文件、API、渲染等能力 | Tool | 工具本身不是员工 |
| 独立、持续、可验收的责任 | Agent | 责任、上下文、权限或生命周期确实独立 |
| 经授权的稳定上下文 | Memory | 不把原始聊天全部长期保存 |
