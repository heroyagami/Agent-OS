# Voice Command 工作流

> 定义语音作为统一任务入口的安全流程。它不包含音频采集、语音识别服务或宿主运行时。

## 输入

宿主提供的转写结果、语言、置信度、会话认证状态和必要的私有对象引用。原始音频和完整转写不进入公开仓库。

## 阶段

| 阶段 | 动作 | 通过条件 | 不通过时 |
| --- | --- | --- | --- |
| Capture | 由宿主接收语音并转写 | 有转写引用、来源和语言 | 宿主不支持时改用文本入口 |
| Parse | 识别意图、动作和目标实体 | 意图明确，实体可定位 | unknown 或歧义则澄清 |
| Resolve | 匹配人员、案件、文件、金额、日期 | 关键对象唯一且版本明确 | 回显候选对象，请用户确认 |
| Risk | 评估 T0–T3 和外部影响 | 风险级别及审批要求明确 | 高风险转人工审查 |
| Authenticate | 检查已认证会话和工具权限 | 会话认证有效，权限覆盖动作 | 拒绝或请求授权，不以声纹替代 |
| Confirm | 对歧义或高影响动作回显动作与对象 | 用户明确确认，原有审批完成 | rejected / approval_required |
| Dispatch | 创建任务契约并进入 Agent Dispatch | 任务ID、幂等键、权限和预算齐备 | blocked 并报告原因 |
| Feedback | 回显状态、阻塞和结果引用 | 状态与宿主证据一致 | 明确说明未执行或未验证 |

## 置信度与消歧

置信度不是授权。低置信度、噪声、否定词不确定或关键实体识别不完整时，不自动派单。人名、案件、文件、金额、日期和收件对象属于关键实体；出现多个候选时必须澄清，不得按最近使用或模型猜测默认选择。

## 高影响动作闸门

发布、删除、对外发送、付款、客户数据外发、生产变更和 T3 任务必须：
1. 显示具体动作与目标对象；
2. 在已认证账户会话中获得明确确认；
3. 通过原有工具权限与审批流程；
4. 记录确认及审批引用；
5. 执行后回读最终对象或结果证据。

声纹、声音相似度和音色识别不作为账户认证或审批凭证。

## 隐私与日志

- 公开仓库只保存 Schema、工作流、模板和脱敏测试。
- 原始音频、完整转写、客户信息、案件材料和凭据留在受控私有系统。
- 任务日志仅保留命令 ID、意图类型、风险、确认状态、任务引用和结果引用。
- 用户拒绝、取消或撤回时，停止未执行动作；已产生的外部副作用按既定撤销/补偿流程处理。

## 能力边界

GitHub 仓库中的 Skill、Workflow 和 JSON Schema 不会打开麦克风、转写音频、识别说话人或启动 Agent。只有接入实际语音入口、STT、已认证会话、任务队列和权限控制，并通过隔离测试后，才能称为语音指挥已部署。
